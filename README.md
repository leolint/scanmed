# Scanmed — попередній перегляд дизайну

Повна статична головна сторінка з хедером і футером.

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.

Адреса після публікації: https://leolint.github.io/scanmed/

Форми у демонстрації вимкнені. Внутрішні посилання та медіафайли ведуть на scanmed.com.ua. Телефонія не підключена. Метатег noindex запобігає індексації демонстрації як копії основного сайту.

Файли: index.html, scanmed-home.css, scanmed-menu.js, fonts/.
